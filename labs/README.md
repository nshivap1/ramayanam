# Labs

Experiments live here: `npm run new-game -- <id> --labs`. Same shape as a game, lighter requirements (see docs/GAME_CONTRACT.md §1). Labs games are hidden unless the player turns on Labs in Profile → Settings (or opens the app with `?labs=1`). Promote a finished experiment by moving its folder to `src/games/` and completing `e2e.spec.ts` and `PRD.md`.
