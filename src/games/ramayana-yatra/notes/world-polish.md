# world-polish notes (maps + writing quality pass, after story-a / story-b)

Owner of: `content/story-common.json`, `content/story-ch1.json` … `story-ch6.json`, this file.
The JSON is the source of truth. My tools live in `/home/claude/scratch/world-polish/`:

| file | what it does |
|---|---|
| `wp.py dump` / `wp.py apply [ids]` / `wp.py check` | Round-trips every map through ONE unified ASCII legend (`maps/<id>.txt`, editable; `ann/<id>.txt` shows npcs `0-9a-z`, warps `@`, triggers `%`). `apply` rebuilds each map's legend from the chars used, runs `edits.py`, then validates (npcs/warps/triggers/signs/shrines reachable from every entry point, open border, encounter maps keep reachable kusha, walkthrough `reach` tiles walkable) and only writes when clean. |
| `edits.py` | Entity moves, the item chests (event + once-trigger), and the optional hotspot npcs/events. Idempotent. |
| `textfix.py` | The writing pass (string fixes, objective normalisation, verse recaps, extra teaching beats, missing objectives). Idempotent: rerun after any regeneration. |
| `render.py OUT [--light] [--nodebug] [ids]` | Renders full maps to PNG with the real `art.ts` (playwright + esbuild bundle of `artentry.ts`). `--light` applies the map's lighting; debug mode outlines warps (cyan), triggers (yellow, dashed) and signs (magenta). |
| `text.py` | Dumps every line of text (`text_dump.txt`) and flags Devanagari/IAST characters, unknown `{w:}`/`{n:}` ids, and lines over 3 sentences / 230 chars. Currently: no script/ID problems; 7 lines of 4 very short sentences, left as they are. |
| `before/`, `after/`, `after_lit/`, `compare/chN_before_after.png` | PNGs. `before/` = story-a/b originals (a backup of the original JSON is in `orig/`). |

## Writing
- Read every event. The tone was already warm and respectful. Changes:
  - **The script hint was wrong.** The in-game menu has no Script setting; the script follows the Samskuru profile. The intro's menu line and the child's hint now say so. The intro also names the menu tabs with `{n:ui.words}` / `{n:ui.verses}`, the same labels the Menu shows.
  - **Names unified.** "Visvamitra" became "Vishvamitra" (matching Dasharatha/Vasishtha/Shabari) and "asoka" became "ashoka". "Shloka-kosha" (story-b) became "verse book" (story-a's term); the word/verse-book hints mention `{n:ui.words}` / `{n:ui.verses}`.
  - **Objectives.** All of them end in a full stop. The "(east)"-style parentheticals became natural phrases. Objectives were added after each of the three Vasishtha-school debates.
  - **Teaching beats.** After s-dasoham, a line about Hanuman calling himself a {w:dasa}. After s-maranantani, Vibhishana answers ("Then I will give my brother his last rites, with honour.").
  - **Rhythm.** A few 4–5-sentence lines were tightened (Bharadvaja at Chitrakuta, Guha, Rama at the deer, Danu, Svayamprabha).
- Lexicon safety: no story text uses `{w:aham}`, `{w:kimcit}`, `{w:kincit}` or `{w:asmad}`, so sa-review's possible merges cannot break a reference. `textfix.py` asserts that every `{w:}` id exists.
